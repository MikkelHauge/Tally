# Tally

Tally is a statistics addon for World of Warcraft Forever.

It records a LOT of things (a few things are not tested, and a lot of  things are not fully tested in WoW Forever - Some testing was done in a mix of Retail and Classic WoW)

What is tracked:

- **Character** - overview, professions by level, milestones, timeline, and a
  Social view (group time, guild history, guild chat messages per guild, chat
  by channel, whispers, trades, mail, duels, and the races/classes met).
- **Playtime** - sessions, level-ups, `/played` sync, alive/afk time.
- **Economy** - balance history, income/expense ledger, trades, auction
  activity, professions, and Merchant's Favor on Forever.
- **Combat** - fights, kills, deaths, buffs and debuffs.
- **Loot** - looted, gathered and crafted items, quality, value and best finds.
- **Explore** - zones, dungeons, distance, flights and mounted time.
- **Total** - per-character and combined figures, records, logs and graphs.

in addition to that, the settings allows for deleting and resetting character data, NOT tracking specific t hings like combat, and such.
